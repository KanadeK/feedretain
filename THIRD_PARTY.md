# Dependencies and references

No runtime dependencies are bundled or required. Python and its standard library
are external prerequisites under the PSF license. Development tools are pytest
(MIT), coverage.py (Apache-2.0), Ruff (MIT), build (MIT) and setuptools (MIT), with
their own transitive dependencies, installed separately.

The [RSS specification](https://www.rssboard.org/rss-specification), Apple
Podcasts migration guidance and IAB measurement guidance informed requirements;
no implementation code, feed content or data was copied. Test and demo feeds are
original fictional examples. Official CI actions are pinned to verified SHAs,
with read-only repository permissions and no code-writing bots.
